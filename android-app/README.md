# Anixart Offline (Android)

Неофициальное Android-приложение для загрузки серий Anixart и просмотра без интернета. Онлайн смотреть удобнее в официальном приложении — это приложение для того, чтобы скачать серии и смотреть их там, где нет сети.

- вход тем же аккаунтом Anixart; ваши списки «Смотрю», «В планах» и др.;
- поиск, выбор озвучки, источника, качества и серий для загрузки;
- загрузки по тайтлам: сортировка, фильтры (не досмотрено / досмотрено / качаются), занятое и свободное место;
- плеер для скачанного: скорость, замок экрана, двойное касание для перемотки, «пропустить», картинка в картинке, растянуть/вписать, следующая серия;
- продолжение с места остановки;
- отметки «просмотрено» уходят в аккаунт; без сети копятся и отправляются позже.

Скачать: релизы с тегом `android-v…` на странице [Releases](https://github.com/pipo3355/anixart-pc/releases).

## Сборка

Веб-часть — `src/` (собирается esbuild в `www/app.js`), нативная — `android/` (Capacitor).

```bash
npm install
npm run sync          # собрать веб-часть и скопировать в android/
cd android && ./gradlew assembleDebug
```

Релизы собирает GitHub Actions (`.github/workflows/android.yml`): Actions → Android → Run workflow. Нужны секреты `ANDROID_KEYSTORE_BASE64` и `ANDROID_KEYSTORE_PASSWORD` — постоянный ключ подписи, без него новая версия не встанет поверх старой.
