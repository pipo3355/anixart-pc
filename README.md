# Anixart PC

Неофициальный клиент Anixart для Windows. Работает с тем же аккаунтом, что и приложение на телефоне: списки, избранное, история и отметки просмотренных серий синхронизируются через серверы Anixart.

> **Это неофициальный проект.** Он не связан с разработчиками Anixart и не поддерживается ими. Приложение использует неофициальный API, который может измениться в любой момент. Пользуйтесь на свой страх и риск.

## Скачать

Последняя версия — на странице [Releases](https://github.com/pipo3355/anixart-pc/releases/latest): файл `Anixart-PC-Setup-<версия>.exe`.

Установщик не подписан, поэтому при первом запуске Windows может показать «Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

Обновления приходят сами: приложение проверяет их при запуске, скачивает в фоне и предлагает перезапуститься.

## Android

Для телефона есть отдельное приложение **Anixart Offline** — загрузка серий и просмотр без интернета. Оно в папке [`android-app/`](android-app/), сборки — в релизах с тегом `android-v…`.

## Возможности

- вход по логину и паролю Anixart (токен хранится зашифрованным средствами Windows);
- поиск, «Обновления» (новые серии по подпискам), расписание по дням недели;
- списки «Смотрю / В планах / Просмотрено / Отложено / Брошено», избранное, история;
- страница тайтла: статус, избранное, выбор озвучки и источника, серии;
- свой плеер (Kodik, Sibnet, VK, OK, Rutube, AniLibria) с выбором качества;
- продолжение с места остановки и автопереход на следующую серию;
- серия отмечается просмотренной в аккаунте после 85% просмотра;
- скачивание серий и просмотр без интернета;
- без интернета открываются сохранённые страницы тайтлов, списки и расписание;
- отметки, сделанные без сети, уходят в аккаунт, когда сеть появится;
- настройки: тема, акцентный цвет, шаг перемотки, длина пропуска опенинга;
- автообновление.

## Горячие клавиши плеера

| Клавиша | Действие |
| --- | --- |
| Пробел / K | пауза |
| F, двойной клик | полный экран |
| M | звук |
| ← / → | перемотка (шаг меняется в настройках) |
| Shift + → | пропустить опенинг (длина меняется в настройках) |
| ↑ / ↓ | громкость |
| N / P | следующая / предыдущая серия |
| F12 | инструменты разработчика |

## Нашли ошибку или есть идея?

В приложении: **Настройки → О программе → «Сообщить о проблеме»** или **«Предложить идею»** — откроется форма с уже заполненной версией. Или сразу в [Issues](https://github.com/pipo3355/anixart-pc/issues/new/choose).

## Где хранятся данные

`%APPDATA%\Anixart PC`:

- `session.bin` — токен входа (зашифрован);
- `progress.json` — на каком месте остановились в каждой серии;
- `settings.json` — настройки;
- `pending-marks.json` — отметки, которые ждут интернета;
- `cache\` — сохранённые страницы для офлайн-режима;
- `downloads\` — скачанные серии.

При удалении программы эта папка не стирается.

## Для разработчиков

Нужен [Node.js](https://nodejs.org) 20 или новее.

```bash
npm install
npm start          # запуск из исходников
npm run dist       # установщик в dist/
```

### Выпуск новой версии

1. Поднять версию: `npm version patch` (или `minor`) — это изменит `package.json` и создаст тег `vX.Y.Z`.
2. Отправить: `git push --follow-tags`.
3. GitHub Actions соберёт установщик и выложит релиз. Установленные копии увидят обновление в течение нескольких часов или при следующем запуске.

Без тега: поднять версию в `package.json`, отправить коммит и запустить **Actions → Release → Run workflow** — тег создастся сам.

### Структура

```
main.js            главный процесс: API, сессия, прогресс, плеер, обновления
downloads.js       очередь загрузок и раздача скачанного плееру (anixdl://)
preload.js         мост для главного окна
player-preload.js  мост для окна плеера
renderer/          интерфейс и плеер (HTML/CSS/JS без сборщика)
build/             иконка
```
